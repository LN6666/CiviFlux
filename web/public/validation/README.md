# Public Baku map extract

`baku-indirect.json` is a small derived GIS extract for the retrospective Baku F1 comparison and a separate candidate active-mobility overlay. Its geometries come from the Geofabrik Azerbaijan OpenStreetMap extract dated 2026-09-18 (source SHA-256 `5134c55378dda62dfe4257b6aa7eec06fe9c67594f7e578bcd6186fbaac5c363`). Road and pedestrian-area data: © OpenStreetMap contributors, ODbL 1.0; see <https://www.openstreetmap.org/copyright>. This data attribution and license apply independently of the CiviFlux code license.

The extract can be regenerated with `scripts/baku_indirect_map.py` from the hashed local motor and multimodal CityPacks and two official announcement pages. The bus comparison uses only the motor-drivable CityPack and the `bus` permission class. The separate multimodal CityPack adds dedicated walking/cycling linear candidates; explicitly tagged OSM pedestrian areas are shown as polygons. These additions have **no event restriction mapping or impact score**. All published closure edges are unreviewed mapping candidates. AYNA layers reflect announced street names mapped to OSM candidate geometries, not operated bus traces. The extract contains no observed event traffic or measured impact.

`baku-active-indirect.json` is a second, independently generated small overlay from `scripts/baku_active_indirect_probe.py`. It shows only candidate walking/cycling lines intersecting a declared 15 m buffer around the unreviewed BCC motor-road candidate and synthetic baseline routes. Its summary also records a 0.2 m colocated-geometry sensitivity, typed assumed-restriction ActionRecords, fixed speed assumptions and OD reachability. **Neither buffer is a claim that the 2026 race closed those active-mode paths.** OSM attribution and ODbL above also apply to this file.

`berlin-local.json` and `berlin-placebo-local.json` are Git-ignored local GIS bundles because they contain VIZ/HERE road-level feed geometry. The second is a pair of real snapshots collected **before** the announced 26 Sep incremental restriction; its colored overlap is background coincidence, not race-day hit rate. See `docs/BERLIN_2026_MAP_VALIDATION.md` for source hashes, regeneration commands and the published aggregate-only placebo evidence.
