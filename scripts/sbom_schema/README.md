# Vendored CycloneDX validation schemas

These unmodified JSON schemas come from the official CycloneDX specification's
`1.6` tag. Exact URLs and SHA-256 digests are in `sources.json`; the generator
verifies those bytes before validating its output without network access.

The schemas identify their license as Apache-2.0. The local license copy is
`LICENSE`. They are validation data, not installed executable dependencies.
